# Классификация NIRS-сигналов

Код курсовой работы по обработке и классификации сигналов функциональной ближней инфракрасной спектроскопии (fNIRS).

В работе исследуются методы распознавания двигательных состояний по сигналам оксигенированного (HbO) и деоксигенированного (HbR) гемоглобина. Рассматриваются методы из диссертации М. Р. Исаева (2025) и эксперименты на двух наборах данных: **NIRS_BCI** и **NITRC**.

```text
├── nirs_bci/              # Обработка сигналов, модели, метрики и эксперименты

├── uv.lock                # Зафиксированные версии зависимостей

```

## Эксперименты

### 1. NIRS_BCI — классификация двигательных состояний

**Ноутбук:** [`01_nirs_bci.ipynb`](notebooks/01_nirs_bci.ipynb)  
**Конфигурация:** [`nirs_bci.yaml`](configs/nirs_bci.yaml)

Эксперименты на восьми сессиях одного испытуемого:

- Спектральный анализ и предобработка сигналов.
- Сравнение LDA и QDA при различных вариантах фильтрации.
- Отбор информативных каналов.
- Обучение с использованием предыдущих блоков и сессий.
- Сравнение LDA, SVM и CatBoost.

Рассматриваются две задачи: различение движений левой и правой руки (`left_vs_right`) и различение состояния покоя и двигательной активности (`rest_vs_active`).

### 2. NITRC — классификация пациентских записей

**Ноутбук:** [`02_nitrc.ipynb`](notebooks/02_nitrc.ipynb)  
**Конфигурация:** [`nitrc.yaml`](configs/nitrc.yaml)

Воспроизводится двухэтапная схема классификации: сначала покой против двигательной активности, затем движение левой против правой руки. Используются хронологическое обучение на предшествующих блоках и сессиях, оконная классификация и варианты регуляризации ковариационной матрицы. Результаты сопоставляются с опубликованными значениями.

## Установка

Из корня проекта выполните:

```bash
uv sync --locked --python 3.12 --extra notebook
```

Команда создаст виртуальное окружение `.venv` и установит необходимые библиотеки.

## Подготовка данных

Исходные данные не входят в репозиторий. Разместите их следующим образом:

```text
data/
├── NIRS_BCI/
│   ├── Day_1.mat
│   ├── Day_2.mat
│   └── ...
└── NITRC/
    ├── MATLAB_Concentrations/
    │   └── *_concentrations.mat
    └── MATLAB_Classification/
        └── classification_summary.csv
```

Набор **NIRS_BCI** предоставлен научной группой. Пациентский набор **NITRC** доступен [здесь](https://www.nitrc.org/frs/?group_id=1650). Файл `classification_summary.csv` используется для сравнения с результатами авторов.

Пути к данным задаются в `configs/nirs_bci.yaml` и `configs/nitrc.yaml`.

## Запуск

Из корня проекта запустите JupyterLab:

```bash
uv run --no-sync jupyter lab
```

Либо откройте проект в VS Code с расширениями Python и Jupyter. Выберите в ноутбуке ядро Python из `.venv` проекта и выполняйте ячейки сверху вниз.

Параметры экспериментов хранятся в `configs/`, результаты новых запусков — в `output/`.

Полный отбор каналов вычислительно затратен и по умолчанию отключён. Чтобы выполнить этот эксперимент, установите в `configs/nirs_bci.yaml`:

```yaml
experiments:
  channel_selection:
    enabled: true
```

## Проверки
